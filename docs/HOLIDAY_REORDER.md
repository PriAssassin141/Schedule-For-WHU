## 对现有工程的理解

- Flutter / Dart，Android 和 Windows；`main.dart` 在桌面初始化 SQLite FFI，并通过 Provider 提供 `AppState`。
- `Course` 保存星期、节次、周次、教师、地点和颜色；`Weeks` 解析与筛选周次，学期最多 22 周。
- `HomeScreen` 的 `FullWeekSchedule` 显示七列课表，原实现直接按当周和课程星期过滤；重叠课程分栏，点击/长按编辑或删除。
- `AppDatabase` 的 `courses`、`exams`、`settings` 三张表保存全部本地数据；`AppSettings` 使用键值行存储，新增键不需要变更表结构。
- 文件导入由 `schedule_importer.dart` 与 `schedule_parser.dart` 负责；本功能与课程导入兼容，也会对之后导入的课程即时重新计算。
- 考试是独立的具体日期事件，不随课程调休改变。

## 使用方式

1. 主页右上角菜单 →「节假日与调休」。
2. 开启「智能重排课表」。默认关闭，以保留老用户升级前的课表行为。
3. 默认使用国家安排；如果学校完全采用自己的安排，可关闭「使用国家节假日安排」，保留手动规则。
4. 点击国家安排可覆盖其停课/补课方式，或点击右上角 `+` 添加日期。
5. 补课可选原日期，并预览课程；可勾选「同时将原日期设为停课」。该停课作为独立规则保存，修改或删除补课后也需要单独管理。
6. 删除手动规则会恢复该日期的国家安排（如开启），否则恢复原课表。选择「按原课表上课」可覆盖国家假日或调休。
7. 也可点击课表表头的日期，直接编辑该日期。

## 重排规则

总开关关闭时只展示原始课表。开启后按实际日期依次选择：手动规则 → 已启用的国家规则 → 原课表。

| 日期安排 | 课表行为 |
| --- | --- |
| 停课 | 当天无课程，包括原来的周末课 |
| 补课 | 用原日期的星期和教学周次筛选原始课程，替换当天整天课表 |
| 按原课表上课 | 忽略国家安排，用实际日期的原始课程 |
| 无安排 | 用实际日期的原始课程 |

例如开学日期为 `2026-09-07`，`2026-09-20` 建议补 `2026-10-06` 的课。
实际授课日处于第 2 周，而课程筛选使用第 5 周周二；只在第 5 周上的课会正确出现在 9 月 20 日周日列。
10 月 6 日作为国家放假日期停课。

补课来源总是原始课表，不递归追踪来源日期上的其它调课规则；循环或互换调课不会无限递归。
学期外来源或实际日期无课程，避免旧 `weekOf` 钳制到第 1/22 周导致误显示。
手动补课编辑器要求两个日期都在当前学期 1～22 周内。
重排不改变课程表记录，不顺延整个学期，也不自动补回所有法定假日课程。

`CourseOccurrence` 单独保存实际日期与来源日期，引用原 `Course`。
因此同一原课程可以出现在不同实际日期，分栏按每次实际授课独立计算，点击补课卡片仍编辑原课程。
点击课程卡片现在先显示居中的玻璃课程信息卡片，再通过「编辑」按钮进入原课程编辑页。
信息卡显示地点、老师、周次、节次与时间、实际日期、备注；补课额外显示原课表日期。
卡片右上角提供删除入口，确认后才删除整门课程；点击关闭或遮罩不会修改课程。
分享课表复用同一个日期解析器，并显示停课/补课说明。

## 国家数据来源与建议的补课对应日期

- [国务院办公厅关于2025年部分节假日安排的通知](https://www.gov.cn/zhengce/zhengceku/202411/content_6986383.htm)，国办发明电〔2024〕12号。
- [国务院办公厅关于2026年部分节假日安排的通知](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)，国办发明电〔2025〕7号。

放假区间和调休上班日期根据上述通知内置。国务院通知不规定学校补哪天的课；下列对应关系是应用建议，界面明确标为「建议」，应按学校通知手动修改。

| 年份 | 实际补课日 → 建议原课表日期 |
| --- | --- |
| 2025 | 1/26 → 2/3；2/8 → 2/4；4/27 → 5/5；9/28 → 10/7；10/11 → 10/8 |
| 2026 | 1/4 → 1/2；2/14 → 2/20；2/28 → 2/23；5/9 → 5/5；9/20 → 10/6；10/10 → 10/7 |

年份选择支持 2025—2035。2027—2035 年预置法定节日日期，开启国家安排后自动停课；尚未公布的连休、补班和补课安排由手动设置补充，不推测为国家正式方案。
已有年度安排公布后，可在 `HolidayCalendar` 添加实际放假区间与调休日期，替换对应年份的基础节日数据。

法定假日范围依据 [2024年修订的《全国年节及纪念日放假办法》](https://app.www.gov.cn/govdata/gov/202411/12/521605/article.html)：元旦一天，春节除夕至正月初三四天，清明一天，劳动节五月一至二日两天，端午与中秋各一天，国庆十月一至三日三天。

## 统一界面样式

`GlassDialog`、`GlassDialogButton`、`GlassSelect` 都复用原 `LiquidGlass`，尊重液态玻璃开关、卡片模糊、透明度、饱和度与色散设置。信息卡、调休编辑、删除确认、年份/节次选项、日期与时间弹窗均采用透明外壳和相同玻璃面板，不再混用白色卡片和不透明绿色弹窗。
日期选择器使用玻璃面板中的 `CalendarDatePicker`，时间选择器采用24小时滚轮；开学与考试日期可选至2035年末。
主题颜色改变时 `MaterialApp` 同步更新，日历选择色与其它控件保持一致。
调休页面已移除国务院通知跳转按钮和限定2025/2026的字样，数据来源仅在工程说明中保留。

## 本地存储与兼容性

在原 `settings` 表增加三个键：

- `holiday_adjustment_enabled`：总开关，缺失时为 0。
- `use_national_holidays`：国家安排开关，缺失时为 1。
- `schedule_adjustments`：手动规则的 JSON 数组，缺失时为 `[]`。

保持 SQLite schema version 1，原课程和考试表不变。损坏的单条手动规则会被忽略。
设置写入成功后才更新内存状态；失败时页面提示重试。
首次默认设置使用批量写入并等待完成，避免首次加载和默认初始化竞争。

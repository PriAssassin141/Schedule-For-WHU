# 日程与三种视图

主页右上角按钮后的玻璃下拉提供「课程」「日程」「课程＋日程」三个选项，选择结果保存在本地，重启后恢复。首次升级仍默认显示原全周课程表。

- **课程模式**：保留一周七天、13节课程同屏和上下翻周、导入、分享、调休等原功能。
- **日程模式**：选择日期后，按实际开始时间列出当天日程。日期栏支持左右滑动浏览相邻七天，保持选中的星期；可点日期切换当天安排，或点日期摘要旁的「回到今天」返回、点顶部年月打开日历。支持2000—2100年的日期。
- **课程＋日程模式**：按一天的实际时分混排课程与日程。课程的节次转换为原有武大课程时刻，继续按周次和调休规则筛选。日程固定在用户选定的实际日期，不参与课程调休。

## 添加与管理

日程视图右上角「＋」或空状态「添加日程」直接进入表单；混合视图「＋」可选择课程或日程，课程模式菜单也提供「添加日程」。从课程模式新增日程后会切到混合视图并定位到保存的日期。

日程可设置名称、开始日期与时分、结束日期与时分、类型、地点、描述。类型包括学习、工作、会议、运动、生活、出行、其他。时间精确到分钟，不依赖课程节次。名称必填，结束必须晚于开始；跨午夜或多天安排应明确选择结束日期。

类型选择列表最底部的「增加自定义类型」可添加1—20字的自定义类型，保存后可在其他日程中选择，重启或删除日程后仍保留；重复名称不会重复添加。卡片颜色支持预设和自定义六位十六进制颜色值（例如 `#68BFA8`），「跟随类型」恢复默认配色。颜色在列表和详情中一致显示。

日期块采用紧凑的54高度，星期、日期与日程标记居中；空日程状态的图标、说明和添加按钮在卡片中居中。

开启液态玻璃后，日期选中透镜连续滑动并在到位后回弹。视图菜单保持玻璃模糊与反光，以固定宽度从按钮下方展开（300ms），并向上折叠收回（180ms）；不对整块玻璃做透明度或缩放动画。开启果冻时展开末尾保留轻微回弹。展开中再次点击会从当前高度连续收回；选择栏目后，等菜单收完再更改下方页面，避免背景突变。关闭果冻后取消回弹，高斯模式保留简洁的折叠过渡，系统减少动态效果时菜单立即开合。日期块无底部阴影，Dock 按钮不使用会残留在背景上的水波纹。

点击卡片先查看玻璃详情窗，点击「编辑」再修改；删除需确认。保存失败保留表单以便重试。日程卡片沿用共享液态玻璃/高斯模糊、主题色、壁纸和减少动态效果设置，详情沿用增强可读性的深色玻璃弹窗。

## 日期与重叠

卡片按开始时间、结束时间和名称排序，相同时间的安排都保留显示，并提示「时间重叠」。相邻的一项结束恰好等于另一项开始时，不算重叠。

跨日安排在涉及的每一天显示，详情保留完整起止日期；结束为次日00:00时不会在次日产生额外卡片。学期以外的日程仍可查看；混合模式不会把学期外日期误当成第1周或第22周。更改开学日期或导入、替换课表不改动独立日程。

## 存储和升级

SQLite自动从版本1/2升级到版本3。版本1新增 `agenda_events` 表及时间索引，版本2在原日程表新增可空的 `custom_category` 和 `custom_color` 字段；原有日程继续使用内置类型与配色。原课程、考试、调休和个性化设置保留，视图模式及自定义类型列表作为独立设置保存。日程数据仅保存在手机本地。

开发调试时，新增设置字段或变更数据库版本后应执行 Hot Restart（`flutter run` 终端输入大写 `R`），让状态与数据库重新初始化。类型列表的读取另有空值兜底，避免保留的旧实例在复制设置、切换液态玻璃时产生空值异常。

验证用例：

```powershell
flutter test test/agenda_event_test.dart test/agenda_database_test.dart test/agenda_ui_test.dart
flutter test --enable-impeller tools/agenda_preview_test.dart
```

第二条命令仅用于显式生成预览，输出位于 `artifacts/agenda-preview/`。
